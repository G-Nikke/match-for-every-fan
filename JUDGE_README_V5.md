# Match for Every Fan — Demo V5

Run `START_DEMO_V5_AI.cmd` and enter a Microsoft Foundry resource endpoint, image deployment and API key locally. Open http://127.0.0.1:3008. The key is masked and is not saved. A page preview without AI is available through `START_DEMO_V5_LOCAL.cmd`.

The viewer accepts the credited sample, a local permitted clip, or a browser window. AI Mode uses a Foundry image model for sampled scene descriptions or short live calls. The viewer can choose simple, professional or excited tone and browser speech. The new **Summarize this segment** button sends the preceding AI commentary lines to the same model, receives a short recap, and pauses the video while it is shown. It does not send another frame.

The app uses local caps of 36 picture checks and three recaps per launch. The recap represents previous AI calls; unobserved play between samples is unknown. Player names and goal calls require a viewer-entered cue. The included sample video and separate synthetic-event replay are credited in `ASSET_CREDITS_V4_1.md`; the sample is not a live league feed.
